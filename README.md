# 📝 Next.js Todo App

A modern, feature-rich Todo List application built using **Next.js 14**, **TypeScript**, and **DnD Kit**.

## 🚀 Features
- Add, delete, and complete todos
- Drag & drop reordering
- Filter todos (All / Active / Completed)
- Due date support with status indicators
- Clean and responsive UI
- Keyboard accessible drag & drop

## 🛠️ Tech Stack
- Next.js (App Router)
- React
- TypeScript
- DnD Kit
- CSS

## 📦 Installation
```bash
git clone https://github.com/pawan-25k/To-Do-List.git
cd To-Do-List
npm install
npm run dev
